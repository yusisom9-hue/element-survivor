# 元素幸存者 (Element Survivor) · 游戏设计思路

## 一、这是一个什么游戏

一款"弹幕生存"小游戏：你控制一个小人在空旷场地上生存，
敌人从四面八方不断涌来，越到后期越多、越强。

你不需要手动攻击——所有武器全自动开火。
你要做的只有一件事：走位。躲避敌群、捡拾经验、活得更久。
死亡后结算分数（击杀 + 反应 + 存活时间 + 等级），本地保存最高分。

双击 HTML 文件即玩，无需安装任何东西。


## 二、核心循环

杀敌 → 掉落经验晶体 → 拾取升级 → 三选一强化卡 → 变强 → 杀更多敌人

升级卡分三类，三者竞争同一个卡池：
  1. 武器　　最多装备 6 把，每把可升 8 级
  2. 被动　　移速 / 生命 / 拾取范围 / 伤害 / 攻速 / 回血 / 暴击，各 5 级
  3. 反应融合　强化某一种元素反应的效果，各 5 级

卡池规则：反应融合卡只在你拥有相关元素的武器后才会进入卡池
（例如拿了火或雷，才会刷出"超载·过载"；拿了风才会刷出"扩散·卷动"），
保证刷出来的强化都是当前 build 打得出来的反应。
每次三选一可以刷新一次候选（R 键或点击刷新按钮），
把这一轮卡池洗成更想要的组合；连续升级时每个候选单独计一次刷新。

设计取舍：武器多而杂会互相稀释（卡池竞争），
"专精一把武器 + 堆被动"和"铺满 6 把武器打反应"是两条都能走的路线。


## 三、灵魂系统：元素反应

每把武器自带一种元素（火 / 水 / 雷 / 冰 / 风 / 岩 / 草）。

武器命中敌人，会给它"附着"这种元素，持续 4.2 秒；
在附着期间用另一种元素命中它，就触发元素反应：

  蒸发（水+火）、融化（冰+火）—— 这一次伤害大幅提升
  超载（火+雷）—— 爆炸波及周围
  感电（水+雷）—— 持续伤害 + 闪电连锁到附近敌人
  超导（冰+雷）—— 减速 + 易伤（受到伤害增加）
  冻结（水+冰）—— 完全定身，冰冻结束时碎冰爆炸
  扩散（风+任意）—— 把附着元素甩给周围一圈敌人
  结晶（岩+任意）—— 掉落护盾碎片，拾取获得护盾
  燃烧（草+火）—— 持续灼烧，还会点燃附近的草附着敌人
  绽放（草+水）—— 生成"草原核"，延时爆炸
  原激化（草+雷）—— 敌人进入激化状态
  超激化 / 蔓激化 —— 激化状态下下一次雷 / 草命中获得大幅加成
  草原核 + 雷 = 超绽放（追踪弹）
  草原核 + 火 = 烈绽放（大爆炸）

设计关键一：敌人自带原生元素（史莱姆=水、骷髅=冰、电萤=雷……）。
所以开局第一枪就能打出反应，不需要先凑齐两把武器——
这直接解决了元素系统"前期没反馈"的问题。

设计关键二：守卫规则（还原直觉、防止数值失控）——
  · 草不可被风扩散（草原核只响应雷与火）
  · 草不与岩结晶
  · 冻结的敌人免疫持续伤害与位移


## 四、流派构建：为什么融合卡重要

武器决定"元素覆盖"，融合卡决定"反应强度"。

同样拿潮汐弹（水）+ 圣焰环（火）：
  · 点"蒸发·增幅" → 每次蒸发倍率更高，走蒸发爆发流
  · 点"结晶·守护" → 护盾越滚越厚，走站场坦克流
  · 点"超载·过载" → 火雷爆炸连成片，走清屏流

同样的武器组合，不同的融合卡点法，就是完全不同的游戏体验。
这是本作"一局一玩法"的来源。


## 五、节奏与难度曲线

  · 敌人刷新间隔从 1.05 秒逐步压缩到 0.16 秒，每次刷怪数量随时间增加，
    10 分钟后刷怪数继续追加
  · 升级所需经验按二次曲线加速增长：前期几乎不变（第 1 级 8 点），
    40 级 177 点、100 级 645 点——全部技能满级约需 7.1 万经验，
    普通玩家约 24 分钟满级，满级前每一级都有新卡反馈，
    满级时会有一次全满提示
  · 敌人血量成长随时间加速：5 分钟约 6.5 倍、8 分钟 11 倍、
    20 分钟 75 倍、30 分钟 210 倍——后期墙就是靠它立起来的
  · 7 种敌人按时间解锁：0 秒史莱姆/蝙蝠 → 45 秒骷髅 → 55 秒蕈兽
    → 70 秒电萤 → 90 秒巨魔 → 120 秒岩盔
  · 每 75 秒降临一只首领（血厚、撞人疼、给大量经验）
  · 260 秒后开始出现精英怪（金圈标记：伤害 ×1.4、经验 ×2，
    血量 ×3 随时间爬升到 ×4.5），出现频率最高到一半；
    其中约四成是远程精英——它们会与玩家保持距离并发射弹丸，
    逼玩家离开"安全站位"

曲线目标：前 30 秒熟悉走位，2 分钟前第一次面对首领，3~5 分钟构筑成形，
升级节奏拉长到约 24 分钟满级——每一级都保持"变强了"的反馈；
普通玩家一局约 5~10 分钟；理解元素反应、构筑成型的玩家
可以打到 20~30 分钟，最终被不断加速的怪潮淹没。


## 六、平衡是怎么调的（设计原则）

数值不靠拍脑袋，全部经过"无头机器人实测"：
让机器人自动走位、自动选卡，批量模拟完整对局，
统计存活时长、升级节奏、每种反应的实际触发次数、
每把武器在不同等级的实测 DPS，然后按数据调整：

  · 武器 DPS 对齐：以中位数为准，偏离过大的调回主线——
    孢子播种（群体伤害严重超标、单目标也第一）削减；
    雷锁链 / 荆棘藤蔓 / 霜爆新星（明显偏弱）增强；
    每把武器保留自己的岗位：单体、群体、控制、辅助反应
  · 防连锁冰冻：同一敌人解冻后 2 秒内再次被冻结，时长减半——
    冰冻仍是强控制，但不再能把首领永久锁死
  · 护盾修复：护盾吸收伤害同样获得无敌帧（原本护盾期间
    会被围殴瞬间打空，是个隐性陷阱）
  · 反挂机设计：涡旋风眼从"常驻环绕风眼"改为"发射出去的风漩涡"——
    持续 2 秒牵引周围敌人，冷却 8 秒，升级缩短冷却（最低 5 秒）并
    提高伤害。牵引是节奏工具而不是永久护罩，杜绝"站着不动无敌"的
    退化玩法
  · 反应可达性：15 种反应在模拟中全部能被自然触发，
    没有只在特定 build 下才见得到的"纸上反应"
  · 手感参数（磁吸半径、升级经验曲线）沿用实测调优结果：
    磁吸半径 104、升级经验 = 5 + 2.9 × 等级

## 七、操作

  WASD / 方向键移动 · 1 / 2 / 3 选卡 · Esc / P 暂停
  手机浏览器可拖屏虚拟摇杆
  攻击全自动，专心走位就好

暂停时会弹出暂停界面：查看本局统计与当前构筑，
可以继续、重新开始或退出到主菜单。
点击左下角的技能图标（或暂停界面里的构筑图标）
可查看该技能的当前效果与下一级预览——查看期间游戏自动暂停，
关闭后自动回到之前的状态（对局或暂停界面）。
